# 已确认决策

来源：用户在本会话的明确答复及v1.4需求基线。产品规则优先于候选技术建议。

- client/server 顶层；Tauri2/React/TypeScript，FastAPI，PostgreSQL。
- 桌面界面采用浅色黑白灰，少量蓝色强调；用户已否定原灰绿色主题。导航、表单与状态保持统一，设计来源见ui-design-references.md。
- Python后端使用uv管理项目：server/pyproject.toml、uv.lock、.python-version、uv维护的.venv；前端包命令继续用pnpm。
- 单管理员账号密码，多设备同一账号，各设备独立安全会话，无注册/多用户权限。用户确认管理员密码可用6位纯数字；软件允许6至128个字符，不强制字母/符号。
- 本机双IDE独立启动；服务部署这台Mac的OrbStack，允许LAN Mac Intel、Apple Silicon Mac及Windows客户端。系统版本/Windows架构和构建机待实测，不据“不太旧”宣称兼容。
- 日常记录订单、收货、退货；到货=初始接受+问题/待处理，问题货支持部分转接受/退回/换货。
- 每笔纳入订单义务的退货选择补交/减量。原订单量保留，应交与净接受分别计算。
- 真实超收可登记，超出部分待处理；接受前需订单变更。未纳入义务的超收退回不生成补交或减量。
- 数量与单价最多6位；税率百分数最多4位；金额2位，ROUND_HALF_UP，按录入含税/未税口径逐行舍入再汇总。
- 对账默认自然月，可自选区间；收退货用业务发生日期；迟到补录保留真实日期并通过后续调整承接历史确认。
- 草稿可编辑；生效订单追加变更；收退货冲销重录，处理下游依赖；已确认账单/发票保持快照，新增调整。
- 对账、发票独立核对与额度；全部差异人工处理，接受差异必须说明理由并留痕。
- 输入.xlsx/.xls、PDF、PNG/JPG/JPEG，中英文，扫描PDF和图片属于一期；密码文件先解密。
- 一期使用联网模型API，允许发送待解析内容；真实供应商/API、预算及样本暂未准备。

待到对应阶段确认：先补后退及订单关闭等复杂业务边界；设备版本和构建资源；真实模型与评测基线；TLS/会话时效、备份留存及发布工程参数。候选ORM/解析器/工作流依赖不视作额外产品需求。
